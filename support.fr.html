Questions fréquentes

Comment retirer les publicités ?

Ouvrez l'app → Boutique → Premium. C'est un achat unique qui supprime toutes les publicités définitivement et débloque des indices et retours illimités.

J'ai acheté Premium mais je vois encore des pubs / c'est absent sur mon autre appareil

Ouvrez l'app → Boutique → appuyez sur « Restaurer les achats ». Premium est lié à votre identifiant Apple et se restaure automatiquement sur tout appareil connecté avec le même identifiant Apple. Si le problème persiste, vérifiez que vous êtes connecté avec le même identifiant Apple qu'au moment de l'achat, puis contactez-nous avec votre email de confirmation de commande.

Comment fonctionne la synchronisation iCloud ?

Activez-la dans Réglages → Synchronisation iCloud. Vos sauvegardes, statistiques et progression du défi quotidien se synchronisent alors automatiquement entre votre iPhone et votre iPad via votre propre compte iCloud privé. Nous ne voyons jamais ces données — voir notre politique de confidentialité.

Comment supprimer mes données ?

Dans l'app : Réglages → « Réinitialiser les sauvegardes » ou « Réinitialiser les statistiques ». Pour aussi supprimer vos données iCloud : Réglages iOS → votre nom → iCloud → Gérer le stockage du compte → The Caribbean Sudoku → Supprimer les données.

L'app nécessite-t-elle une connexion internet ?

Non — chaque mode de jeu se joue entièrement hors ligne. Une connexion internet n'est utilisée que pour les duels multijoueur en ligne, le classement du défi quotidien, la synchro iCloud, et les publicités dans la version gratuite.

Comment fonctionne le multijoueur 1v1 ?

Vous pouvez affronter un ami en ligne via Game Center, ou en local par Wi-Fi/Bluetooth sans connexion internet — vous courez tous les deux sur exactement la même grille, et le plus rapide à la résoudre correctement gagne.

J'ai trouvé un bug, ou une grille semble incorrecte

Écrivez-nous à contact@caribtechstudio.com avec votre modèle d'appareil, votre version d'iOS et, si possible, une capture d'écran. Chaque grille de l'app a exactement une solution valide ; si quelque chose semble anormal, nous voulons le savoir.
